# WorkFlow SaaS 🚀 - Trello Clone with AI

Live Demo: https://workflow-saas.vercel.app
Backend API: https://workflow-saas.onrender.com/docs

### Features
- ✅ Drag & Drop tasks (Todo / Doing / Done)
- ✅ AI Priority Detection (urgent/bug = high)
- ✅ FastAPI + SQLite DB - data stays after refresh
- ✅ Tailwind CSS + Modern UI

### Tech Stack
Frontend: React, Vite, Tailwind, @hello-pangea/dnd, Axios
Backend: FastAPI, SQLAlchemy, SQLite

### Run Locally
Backend: `cd backend && python -m uvicorn main:app --reload --port 8000`
Frontend: `cd frontend && npm run dev`
